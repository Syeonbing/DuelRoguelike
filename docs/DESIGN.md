## 개요

유희왕 카드로 듀얼을 이어 가며 탑을 오르고 덱을 키우는 로그라이크형 비상업 팬게임이다. 이기면 상대 덱에서 카드를 얻고, 지면 덱 카드가 봉인되지만 런은 계속된다. 덱을 40장으로 채울 수 없게 되면 런이 끝난다.

- 카드 표시: 일러스트 없이 직접 디자인한 텍스트 카드 템플릿에 카드명·효과문·스탯을 넣는다. 일러스트는 게임 기능으로 제공하지 않지만, 카드 ID 이름의 이미지 파일이 있으면 읽어 표시한다 (현재 구현: 있음).
- 효과는 원본 텍스트대로 작동해야 하므로, 오픈소스 엔진과 카드 스크립트로 원작 룰을 그대로 처리한다.
- 참고작: 포켓로그 (런·컬렉션), 림버스 컴퍼니 거울 던전 (선택지 이벤트)

## 지켜야 할 제약

- 비상업. 제목·로고에 "유희왕"을 쓰지 않는다. 앱스토어 대신 개인 배포.
- 공식 카드 레이아웃을 흉내 내지 않는다.
- 일러스트는 배포·링크·자동 다운로드하지 않는다. 플레이어가 직접 넣은 그림 파일만 읽어 보여 준다.
- 연출은 화려한 이펙트 대신 화면 옆 로그에 처리 과정을 글로 남긴다.
- 카드 효과는 원작 룰 그대로 처리한다 (ocgcore + Project Ignis 카드 스크립트·카드 DB). 카드 효과를 바꾸는 아이디어는 비싸다. 아이템 카드의 탑 효과는 듀얼 밖에서만 작용하므로 이 제약에 걸리지 않는다.
- 라이선스: AGPL-3.0, 공개 저장소. 외부 코드는 출처와 라이선스를 기록한다.
- 플랫폼: PC(Windows), Unity 6.3 LTS. 1인 개발, Claude Code와 함께 만든다.

| 귀속 | 아이템 효과를 적용한 귀속 카드가 봉인될 때까지 메인 덱에서 빠질 수 없는 상태 |
| 보유 | 이벤트 조건에서 "가지고 있다"로 치는 범위. 이벤트마다 다르다 |

## 듀얼·덱 규칙

현재 마스터 룰을 기준으로 하되 엑스트라 몬스터 존은 두지 않고, 금제는 적용하지 않는다. 대신 강한 카드는 희귀도를 매우 높게 둔다.

- 카드풀에 펜듈럼·링크가 없으므로 엑스트라 덱 몬스터는 메인 몬스터 존에 바로 소환한다.
- 소환: 일반·어드밴스·반전·특수·의식·융합·싱크로·엑시즈.
- 체인, 데미지 스텝, 효과 발동 타이밍은 현재 룰대로 처리한다.
- 메인 덱 40\~60장, 엑스트라 덱 최대 15장.
- 같은 카드명 3장 제한은 듀얼에 쓰는 덱(메인·엑스트라 덱)에만 있다. 사이드 덱에는 장수·카드명 제한이 없다.
- 런을 시작할 때는 메인 덱과 사이드 덱을 합쳐 카드명당 3장까지.
- 같은 카드명의 기준: 카드 DB의 "같은 카드명 취급(alias)"을 따른다. 에라타 전·후 버전은 같은 카드명으로 합쳐 세고, 섞어 넣을 수 있다.
- 선후공: 코인 토스로 정하고, 이긴 쪽이 선공·후공을 고른다. AI는 대부분 선공을 고른다 (90%, 임시).
- 코인 토스에서 플레이어가 이길 확률은 50%이고, 아이템·보스·이벤트가 바꿀 수 있다 (예: 운이 너무 강해서 반드시 앞면이 나오는 캐릭터). 현재 구현: 아이템으로만 바뀐다 (최대 100%).
- 무승부는 패배로 처리한다. 상대 LP는 늘 8000으로 시작한다.

## 카드풀·희귀도·시작 덱

카드풀은 펜듈럼·링크 등장 이전의 카드 전체다. 목표는 플레이어가 컬렉션으로 직접 덱을 만드는 것이고, 스타터 덱은 어디까지나 임시 덱이다.

- 처음 시작할 때 모든 플레이어에게 같은 스타터 덱 하나를 준다. 지금의 4개와는 다른 덱이 될 예정이다. [미정: 구성]
- 첫 버전 카드: 스타터 덱 —유희 편—, —카이바 편—, —조이 편—, —페가수스 편— 4개 (카드 154종). 현재 구현: 새 게임의 컬렉션은 이 4개 덱의 카드다.
- 첫 버전 이후 추가할 스트럭처 덱 목록 [미정].
- 에라타 카드는 전·후 버전을 모두 쓸 수 있고, 전 버전이 더 희귀하다. 예: 「크리터」(\~2016), 「크리터」(2016\~). 컬렉션에서는 두 버전을 별개의 카드로 센다.
- 희귀도는 대체로 카드 성능을 따르지만, 반드시 그렇지는 않다. 카드 등급은 패치에 따라 바뀔 수 있다. 처음에는 조금 낮게 매기고 필요하면 올린다.

희귀도는 5등급이고, 낮은 쪽부터 N, R, SR, UR, FR 순이다.

| 등급 | 기준 |
| --- | --- |
| N | 넣으면 오히려 손해일 수 있는 카드 |
| R | 쓸 수는 있지만 상위호환이 있는 카드 |
| SR | 어디서나 무난한 카드 |
| UR | SR보다 강한 카드 |
| FR | 밸런스를 심하게 해치는 카드. 예: 「번개」, 「해피의 깃털」, 「고통의 선택」, 「짓궂은 쌍둥이 악마」 |

스타터 덱 임시 등급 (`Assets/StreamingAssets/Data/rarity.txt`). 금지 레어급 카드(예: 「천사의 자비」)도 있지만 FR은 0장이라, 등급을 다시 매기면 분포가 바뀐다.

| 덱 | N | R | SR | UR |
| --- | --- | --- | --- | --- |
| 유희 편 | 35 | 9 | 3 | 3 |
| 카이바 편 | 37 | 10 | 1 | 2 |
| 조이 편 | 28 | 13 | 6 | 3 |
| 페가수스 편 | 26 | 16 | 4 | 4 |

## 탑 구조

탑은 10층 묶음이 반복되고, 층 번호의 끝자리로 층 종류가 정해진다.

| 층 (끝자리) | 종류 | 내용 |
| --- | --- | --- |
| 1\~3층 | 전투 | 층마다 10% 확률로 이벤트 층이 된다 |
| 4층 | 전투 | 30% 확률로 이벤트 층이 된다 |
| 5층 | 칩교환소 | 칩을 쓰는 곳 |
| 6층 | 이벤트 | 반드시 이벤트 |
| 7\~8층 | 전투 | 층마다 5% 확률로 이벤트 층이 된다 |
| 9층 | 휴식 | LP를 8000으로 맞춘다 |
| 10층 | 보스 | 이기면 봉인된 카드 1장 봉인 해제, 없으면 보상 카드 1장 더. LP 8000으로 초기화 |

- 최소 전투 층: 10층 묶음마다 1\~4층 중 1개 이상, 7\~8층 중 1개 이상은 전투 층이다. 지금 확률로는 거의 걸리지 않고, 이벤트 확률을 올리는 카드가 생겼을 때의 안전장치다.
- 층 번호: 비전투 층도 층 번호에 센다. 봉인 공식의 층 항, 승리 보상 확률표, 보스 주기가 모두 이 번호를 따른다.
- 전투 층 = 단판 듀얼 하나. 일반 전투 층의 상대 덱은 무작위로 뽑는다 (보스·이벤트 전투는 정해진 덱). 현재 구현: 상대는 스타터 덱 4개 중 무작위이고, 보스 층도 아직 같다.
- 미리보기: 아이템 없이 바로 위 1층의 종류만 보인다. 카드 효과로 늘어날 수 있다 (예: 「고대의 망원경」 +1층).
- 이벤트 내용: 이벤트 층에 들어가야만 알 수 있다. 10층 묶음 시작 때 미리 정하지 않는다. 특정 수단(아이템 등)으로 특정 이벤트를 확정할 수는 있다.
- 특별한 층: 50층 최종 보스, 100층 히든 보스(FR 확정 지급), 101층부터 무한 모드 [미정: 규칙]. 50층부터 적이 플레이어의 패를 보며 플레이한다.

시뮬레이션으로 본 10층 묶음당 확률 이벤트 개수: 0개 46%, 1개 40%, 2개 12%, 3개 이상 2%.

## 런 진행

전투 층에서 이기면 다음 층으로 가고, 지면 봉인을 받고 같은 층을 새 상대와 다시 한다.

- 승리: 다음 층으로 간다. 승리 보상과 칩을 받는다. 연패가 0이 된다.
- 패배 (무승부 포함): 같은 층을 새로 뽑은 상대와 다시 한다. 연패 +1. 칩은 잃지 않는다.
- 봉인 공식: 메인 덱 봉인 장수 = 연패 횟수 + (층 ÷ 10, 버림). 상한 없음. 예: 25층에서 3연패째면 5장. 봉인할 카드는 무작위다.
- 엑스트라 덱: 패배마다 20% 확률로 1장 봉인, 성공하면 실패할 때까지 반복한다. 1장 이상 20%, 2장 이상 4%, 3장 이상 0.8%, 평균 패배당 0.25장.
- 보충: 메인 덱이 40장 미만이 되면 사이드 덱에서 골라 보충한다. 상점 덱 카드로는 보충할 수 없다.
- 런 종료: 보충할 카드가 없어 40장을 채울 수 없으면 런이 끝나고, 골드를 정산한다.
- 이벤트 전투:
  - 상대는 이벤트마다 정해져 있다.
  - 이기면 그 선택지의 결과(이벤트 보상)만 받는다. 일반 승리 보상은 없다. LP +1000은 받는다.
  - 지면 일반 패배처럼 봉인을 받고 연패에 더한다. 같은 층을 다시 하지 않는다.
  - 어느 쪽이든 다음 층으로 넘어간다 (보충이 필요하면 보충한 뒤).
  - LP는 전투 층과 똑같이 작동한다.

## LP 규칙

LP는 듀얼 사이에 이어지고, 이길 때마다 1000씩 회복하며, 9층 휴식과 보스 클리어 때 8000으로 맞춘다.

| 상황 | LP |
| --- | --- |
| 런 시작 | 8000 |
| 듀얼에서 이김 (보스 제외) | 남은 LP + 1000. 8000을 넘을 수 있다 |
| 듀얼에서 짐 | 8000으로 전부 회복 (8000보다 높게 끝났으면 그대로) |
| 9층 휴식 | 8000으로 맞춘다. 8000보다 많아도 8000이 된다 (회복이 아니라 조정) |
| 보스(10층 단위)를 이김 | 8000으로 초기화 |
| 이벤트 전투 | 전투 층과 같음 |

- 보스 클리어 때 8000으로 맞추는 이유: 다음 묶음의 첫 층을 9000처럼 8000이 아닌 값으로 시작하는 건 부자연스럽다.
- 참고: 시험에서 LP 4000 미만으로 시작한 듀얼의 승률은 30% 안팎, 4000 이상은 50% 안팎이었다.

## 승리 보상

이기면 층별 확률표로 등급을 뽑고, 상대 덱에서 그 등급의 서로 다른 카드 후보 3장 중 1장을 고른다.

- 변형: 2장 중 1장, 2장 모두 받기, 3장 중 2장 등. 이벤트·카드와 엮어 쓴다 (현재 구현: 없음).
- 후보가 모자랄 때: 빈 자리는 골드로 준다.
- 그 등급의 카드가 상대 덱에 없을 때: 골드를 준다. 웬만하면 이런 경우가 없도록 상대 덱을 짠다. 모든 상대 덱에 SR·UR을 최소 1장 넣는다 (50층부터는 FR도 1장).
- 카드 → 골드 환산 (임시): N 1, R 2, SR 4, UR 8, FR 16. 보상 빈 자리, 등급 카드 없음, (나중에) 컬렉션 분해에 같은 표를 쓴다.
- 얻은 카드는 사이드 덱과 컬렉션에 들어간다. 이미 3장 가진 카드여도 받을 수 있다.
- 이번 런에서 잃었던 카드를 다시 얻으면, 새로 얻은 것이므로 컬렉션에 1장 추가된다.
- 보스를 이기면 이 보상에 더해 봉인 해제 1장 (없으면 보상 카드 1장 더).

보상 등급 확률표 (초안, %). 1\~49층은 10층마다 N −5, R +2, SR +2, UR +1%p, 51\~99층은 N −3, R +1, SR +1, UR +1%p씩 바뀐다. 51층부터 생기는 FR 1%는 N에서 뺀다.

- 100층 히든 보스: FR 확정.
- 101층 이후 무한 모드: 90\~99층 확률을 그대로 쓴다.

## 봉인·봉인 해제·봉인 대상 교체

봉인은 그 런에서만 카드를 못 쓰게 하는 것이고, 패배·봉인·이벤트로 카드를 영구히 잃는 일은 없다. 컬렉션에서 카드가 빠지는 건 플레이어가 직접 분해하거나 재료로 쓸 때뿐이다.

- 봉인할 카드는 무작위다. 특정 이벤트는 특정 카드를 반드시 봉인 대상에 포함시킬 수 있다.
- 봉인된 아이템 카드는 탑 효과가 꺼진다.
- 봉인 해제는 매우 귀하게 만든다.
  - 보스(10층 단위)를 이기면 봉인된 카드 1장을 골라 봉인 해제한다. 엑스트라 덱 카드도 고를 수 있다. 봉인된 카드가 없으면 보상 카드를 1장 더 고른다.
  - 칩교환소에서 칩으로도 봉인 해제할 수 있다 (가격·등장 빈도는 칩교환소 절).
  - 풀린 카드는 사이드 덱으로 간다.
- 봉인 대상 교체는 비교적 쉽게 접할 수 있게 한다.
  - 봉인된 카드 하나를 풀고(사이드 덱으로), 같은 덱(메인↔메인, 엑스트라↔엑스트라)의 다른 카드를 대신 봉인한다. 봉인된 장수는 그대로다.
  - 같은 레어도끼리 / 레어도 상관없음 두 종류. 새로 봉인될 카드는 무작위일 수도, 플레이어가 고를 수도 있다.
  - 교체하면 메인 덱이 1장 줄어 40장 아래가 될 수 있다 (그러면 보충). 보충할 수 없게 되는 교체는 팔지 않는다.
  - 칩교환소에서 산다. 이벤트에서도 얻을 수 있게 한다 (현재 구현: 이벤트 결과로는 아직 없음).

| | 봉인 | 이번 런에서 잃음 |
| --- | --- | --- |
| 되돌리는 법 | 봉인 해제 (보스 보상, 칩), 봉인 대상 교체 | 같은 카드를 다시 얻기 |
| 덱 장수(체력) | 줄어듦 | 줄어듦 |
| 컬렉션 | 그대로 | 그대로 |

## 이벤트 시스템

이벤트는 상황 글 → 선택지 → 결과로 진행하고, 결과는 이득·손해·이벤트 전투 중 무엇이든 될 수 있다.

### 구조

- 모든 이벤트에 선택지가 있지는 않다. 선택지 없는 사건형은 결과가 바로 정해지고 "확인"만 누른다.
- 선택지형 이벤트에도 조건 없는 선택지("지나간다" 포함)가 없을 수 있다.
- 모든 선택지가 잠겨도 이벤트는 등장한다. 플레이어가 그런 이벤트가 있다는 걸 알 수 있게 하기 위해서다. 이때는 이벤트에 따라 그냥 지나가거나, 강제 선택지를 고르게 된다.
- 결과로는 거의 모든 일이 일어날 수 있다. 결과 재료: 칩 ±, LP ±, 골드, 카드 얻기(사이드 덱·컬렉션), 봉인, 봉인 해제, 이번 런에서 잃음, 이벤트 전투. (봉인 대상 교체는 아직 없다.)
  - 잃는 칩은 가진 만큼만 잃는다. LP는 1 아래로 내려가지 않는다. 봉인 해제할 카드가 없으면 칩으로 대신 준다.
- 이번 런에서 카드를 잃게 하는 이벤트는 있다. 컬렉션에서 카드를 잃게 하는 이벤트(바치기)는 없다.

### 선택지 조건

- 주사위·동전 같은 판정 대신, 특정 카드명 또는 특정 스펙의 카드를 보유해야 고를 수 있는 선택지로 만든다. 칩 조건도 있다.
- 스펙 조건 예: 종족, 속성, 레벨, 공격력, 카드 종류에 장수를 붙인다 ("드래곤족 몬스터 2장 이상", "함정 카드 5장 이상").
- 보유 범위는 이벤트마다 정한다: 덱(메인·엑스트라) / 덱 + 사이드 덱 / 상점 덱 포함.
- 조건을 만족한 이벤트는 등장 확률이 더 높다. 현재 구현: 강제가 아닌 조건 선택지를 지금 고를 수 있으면 가중치 ×2 (임시).

### 표시와 도감

- 잠긴 선택지는 조건이 보인다.
- 처음 보는 이벤트는 선택지의 결과를 표시하지 않는다.
- 이벤트 도감: 만난 이벤트를 업적처럼 모아서 본다. 셀 선택지를 모두 골라 본 이벤트는 완성이고, 등장 조건과 성향을 확인할 수 있다.
  - 세지 않는 선택지: "지나간다", 결과가 없는 선택지, 강제 선택지. 셀 선택지가 없는 이벤트(예: 고요한 층)는 만나면 완성.
  - 도감은 런을 저장할 때 갱신되고, 런을 포기해도 남는다.

### 성향과 뽑는 방식

- 성향은 긍정·무성향·부정 세 가지다 (혼합 없음). 비율은 긍정 35 : 무성향 15 : 부정 50.
- 성향을 먼저 뽑고, 그 성향 안에서 가중치로 이벤트를 고른다. 그 성향에 나올 이벤트가 없으면 남은 성향에서 뽑는다. 나올 이벤트가 하나도 없으면 "고요한 층"이 나온다.
- 같은 이벤트가 한 런에 다시 나올 수 있는지는 이벤트마다 정한다.
- 칩교환소에 이벤트 성향에 영향을 주는 아이템(카드)을 둔다. [미정: 목록]

### 태그

| 태그 | 값 | 쓰임 |
| --- | --- | --- |
| 자리 | 앞(1\~4층) / 고정(6층) / 뒤(7\~8층), 여러 개 가능 | 어느 층에 나올지 |
| 깊이 | 최소 층, 최대 층 | 몇 층대에 나올지 |
| 성향 | 긍정 / 무성향 / 부정 + 기대값(카드 몇 장어치) | 손익 균형 |
| 형식 | 선택지 / 사건 / 전투 포함 | 템포 조절 |
| 덱 | 공용 / 특정 덱 (런 시작 덱 기준) | 카드명 조건이 있는 이벤트 관리 |
| 가중치 | 숫자 (기본 1) | 드물게 나올 이벤트 |
| 보유 범위 | 이벤트마다 | 조건을 어디까지 볼지 |
| 반복 | 한 런에 다시 나올 수 있는지 | 중복 관리 |

### 견본 이벤트 (현재 구현, 글과 수치는 임시)

형식을 한 번씩 써 보려고 만든 12개다. 이벤트를 고치거나 더할 때는 `Assets/Scripts/Run/TowerEventList.cs`만 고친다. 이벤트 Id는 저장 파일과 도감에 남으므로 바꾸지 않는다.

- 긍정: 반짝이는 동전(사건), 용의 사당(조건 선택지), 은퇴한 듀얼리스트, 백룡의 전설(카이바 편 전용, 6층, 한 번만)
- 무성향: 갈림길, 물물교환, 고요한 층(나올 이벤트가 없을 때)
- 부정: 낙석(사건), 소매치기(사건), 저주받은 거울, 통행세, 매복(이벤트 전투)

첫 버전 풀은 자리별로 앞 6\~8개, 고정 8\~10개, 뒤 3\~4개 정도면 한 런에서 중복 없이 돈다. [미정: 이벤트 내용]

## 재화

런 재화는 칩, 영구 재화는 골드다.

### 칩 (런 재화)

- 얻는 곳: 전투 승리, 보스 승리, 일부 이벤트 (모든 이벤트가 칩을 주지는 않는다). 현재 구현 (임시): 승리 20, 보스 승리 50.
- 쓰는 곳: 보통 칩교환소에서만. 이벤트에서 얻거나 잃을 수 있다.
- 전투 층에서 지면 칩을 잃지 않는다.
- 런이 끝나면 사라지고, 일부가 골드 정산에 반영된다.
- 리롤은 없다 (보상 후보 3장으로 불필요). 원래 용도 중 봉인 해제(매우 귀하게)와 보상 확률 상승은 남는다. [미정: 보상 확률 상승의 방식]
- [미정] 획득량과 가격. "얻은 칩 ÷ 100" 정산 항이 의미 있도록, 칩이 런마다 수백 개 쌓이는 규모로 맞춘다.

### 골드 (영구 재화)

- 얻는 곳: 런 종료 정산, 승리 보상 후보의 빈 자리, 보상 등급의 카드가 상대 덱에 없을 때, 컬렉션 초과분 분해.
- 쓰는 곳: 팩 개봉, 스트럭처 덱 구매, 투입 코스트 제한 임시 완화 (상한 없음, 변경하지 않음), 사이드 덱 확장 (영구·임시).
- [미정] 각 가격.
- 현재 구현: 얻기만 하고 쓰는 곳은 아직 없다.

### 골드 정산 (런 종료 시)

골드 = 도달 층 + 10층 단위 보너스 + (런 동안 얻은 칩 ÷ 100) + (종료 때 가진 칩 ÷ 10). 나눗셈의 나머지는 버린다.

- 도달 층: 런이 끝난 층.
- 10층 단위 보너스: 10층을 클리어했으면 +1, 20층 +2, 30층 +3 …을 모두 더한다.

| 런이 끝난 층 | 도달 층 + 보너스 (칩 항 제외) |
| --- | --- |
| 13층 | 13 + 1 = 14 |
| 31층 (30층 클리어) | 31 + 1 + 2 + 3 = 37 |
| 51층 (50층 클리어) | 51 + 15 = 66 |
| 101층 (100층 클리어) | 101 + 55 = 156 |

## 칩교환소

칩교환소는 10층 묶음의 5층마다 나오는 비전투 층이고, 칩은 보통 여기서만 쓴다.

- 상품마다 한 칩교환소에서 한 번만 살 수 있다. 진열은 런 시드와 층으로 정해진다.
- 교환소에서는 바로 다음 6층 이벤트의 내용을 알 수 없다.
- 들어가면 칩교환소 창이 한 번 뜬다. 닫아도 층 사이 화면에서 다시 열 수 있다.

현재 구현의 상품 (가격·빈도는 모두 임시, [미정: 목록·가격]):

| 상품 | 가격 (칩) | 진열 |
| --- | --- | --- |
| 봉인 대상 교체 (같은 레어도, 새로 봉인할 카드는 무작위) | 30 | 늘 |
| 봉인 대상 교체 (같은 레어도, 직접 고름) | 50 | 늘 |
| 봉인 대상 교체 (레어도 상관없음, 무작위) | 50 | 늘 |
| 봉인 대상 교체 (레어도 상관없음, 직접 고름) | 80 | 늘 |
| 봉인 해제 (봉인된 카드 1장을 골라 사이드 덱으로) | 150 | 칩교환소마다 50% |
| 아이템 카드 1장 (목록에서 무작위) | 카드마다 | 늘 |

- 산 아이템 카드는 상점 덱으로 들어간다. 상점 덱이 같은 카드명 3장, 또는 전체 10장으로 꽉 차면 더 살 수 없다.
- 이벤트 성향에 영향을 주는 아이템도 둔다. [미정: 목록]

## 사이드 덱·상점 덱·컬렉션

카드가 머무는 곳은 메인 덱·사이드 덱·상점 덱(이상 런 중)과 컬렉션(영구)이고, 각각 규칙이 다르다.

| | 사이드 덱 | 상점 덱 | 컬렉션 |
| --- | --- | --- | --- |
| 들어오는 카드 | 런에서 얻은 카드, 시작 시 컬렉션에서 고른 카드, 봉인이 풀린 카드 | 칩교환소에서 산 카드 | 한 번이라도 얻은 카드 전체 |
| 장수 제한 | 런 중 없음 (시작 한도는 아래) | 같은 카드명 3장, 전체 10장. 꽉 차면 구매 불가 | 없음 (3장 넘어도 보관) |
| 보충에 쓰기 | 쓴다 | 못 쓴다 | — |
| 메인 덱과 교환 | 듀얼 밖에서 자유 (귀속 카드 제외) | 못 한다 (사이드 덱으로도 못 옮김) | — |
| 봉인 | 메인 덱에 들어가야 봉인 대상 | 봉인되지 않음 | — |
| 보유로 치기 | 이벤트마다 | "상점 덱 포함" 이벤트에서만 | 이벤트마다 |
| 런이 끝나면 | 사라짐 (얻은 카드는 컬렉션에 남음) | 사라짐, 컬렉션에 안 들어감 | 남음 |

### 사이드 덱 시작 한도

- 처음 3장. 골드로 영구 확장해 최대 10장. 런마다 골드로 임시 5장을 더 사서 최대 15장 (런 시작 때 산다). [미정: 가격]
- 시작 사이드 덱도 메인 덱과 합쳐 카드명당 3장, 투입 코스트 한도를 적용한다.
- 현재 구현: 3장 고정 (골드 확장 없음).

### 컬렉션

- 얻은 장수만큼 이후 런에서 쓸 수 있다.
- 에라타 전·후 버전은 별개의 카드로 센다. 덱의 3장 제한은 카드명 기준으로 합쳐 센다.
- 분해: 골드로 바꾼다. 버전(카드 ID)마다 3장 아래로는 분해할 수 없다 (3장을 넘는 분만). 현재 구현: 없음.
- 재료: 재료로 쓸 수 있고, 이때는 3장 아래로 내려갈 수 있다. [미정: 재료를 쓰는 곳]
- 카드를 영구히 잃는 건 분해·재료로 플레이어가 직접 뺄 때뿐이다.

## 아이템 카드와 귀속

아이템은 카드다. 듀얼 효과는 원작 그대로 두고, 탑 진행에서만 작용하는 탑 효과를 따로 가진다.

- 탑 효과는 카드명 기준이다. 어디서 얻은 카드든 같은 이름이면 같은 탑 효과를 가진다.
- 효과가 나는 위치(메인 덱, 사이드 덱, 상점 덱 등)와 중첩 여부는 카드마다 정한다. 밸런스에 문제가 있는 것은 중첩하지 않는다.

### 적용

- 모든 아이템 카드는 효과를 적용할지, 어느 카드에 적용할지 플레이어가 정한다 (듀얼 밖에서).
- 같은 덱 안에서 한 장이라도 적용되면, 그 덱의 같은 카드명은 전부 적용된 것으로 본다.
- 상점 덱과 메인 덱은 별개로 적용한다.
- 중첩되는 효과는 두 곳의 적용이 합쳐진다. 중첩되지 않는 효과는 두 곳에 적용해도 한 번만 친다.
- 같은 이름의 카드가 그 덱에서 전부 빠지면(전부 봉인, 이번 런에서 잃음, 사이드 덱으로 옮김) 적용이 풀린다. 다시 넣을 때 적용할지는 플레이어가 고른다.
- 봉인된 카드는 탑 효과가 꺼진다.

### 귀속

- 효과만 받고 듀얼 전에 빼는 "넣었다 빼기"가 허용되는 카드도 있다.
- 귀속 카드는 메인 덱에서 효과를 적용하면 귀속도 함께 걸리고, 봉인될 때까지 메인 덱에서 뺄 수 없다.
- 런 시작 때 시작 덱에 넣는 귀속 카드도 같다.
- 메인 덱에 있는 동안에는 런 도중 귀속과 아이템 효과를 마음대로 풀 수 없다.
- 참고: 상점 덱 카드는 봉인되지 않으므로, 중첩되지 않는 효과는 상점 덱에 적용하는 것이 늘 안전하다.

| --- | --- | --- | --- | --- | --- |
| 「고대의 망원경」 | 탑 미리보기 +1층 | 메인 덱·상점 덱 | 안 됨 | 있음 | 60 |

## 덱 편집·투입 코스트

런 시작 덱은 컬렉션에서 짜고, 희귀도별 투입 코스트의 합이 한도를 넘지 않아야 한다.

- 덱은 레시피로 저장하며, 코스트 한도를 넘는 레시피도 저장할 수 있다. 코스트는 런을 시작할 때만 맞으면 된다.
- 투입 코스트 한도는 메인 덱과 사이드 덱 모두에 적용한다.
- 덱이 40장을 넘으면 1장마다 최대 코스트가 2\~3씩 늘어난다. [미정: 2인지 3인지, "40장 초과"의 기준이 메인 덱 장수인지]
- 약한 카드로 덱을 불려 체력을 늘리는 것은 허용한다. 연패할수록 봉인이 늘어나는 구조가 그 대가다.
- 골드로 코스트 제한을 임시 완화할 수 있다. 상한은 없고, 이 원칙은 바꾸지 않는다. [미정: 가격 방식 — 고정 또는 한 런 안에서 누진]
- [미정] 희귀도별 코스트 수치와 기본 한도.
- 현재 구현: 런 시작 화면에서 레시피(스타터 덱 4개와 플레이어 레시피)를 고르고, 덱 편집 화면에서 컬렉션으로 레시피를 짠다 (카드 검색·정렬, 복사, 새 레시피, 지금 덱을 레시피로 저장). 투입 코스트는 아직 없다.

## 저장·무작위 결과

층을 오를 때마다 저장하고, 무작위 결과가 정해지는 순간에도 저장한다. 플레이어가 무작위 결과를 다시 뽑을 수 없게 하는 것이 목적이다.

- 저장 시점: 층을 오를 때, 이벤트 내용을 뽑았을 때, 보상 후보를 뽑았을 때, 듀얼을 시작할 때("듀얼 중" 표시), 컬렉션이 바뀌었을 때.
- 무작위 결과(이벤트 내용, 보상 후보, 봉인할 카드, 코인 토스)는 뽑는 즉시 확정된다.
- 듀얼 도중 강제 종료하면 그 듀얼은 패배로 처리한다.
- 플레이어가 시드를 조정할 수 없게 한다. 현재 구현: 런 시작 화면에 시드 칸이 있다 (시험용, 이 규칙과 다름).
- 이어하기·포기가 있다.
- 현재 구현: 저장 파일 형식 5 (텍스트). 런 상태를 그대로 적고, 무작위는 (런 시드, 번호, 용도)로 다시 계산한다. 옛 형식(1\~4) 파일도 읽는다.

## AI·보스

- 상대 AI는 WindBot(WindBot Ignite)이고, 층이 올라갈수록 강해진다. 현재 난이도는 하나뿐이다. [미정: 1\~49층에서 층별로 강해지는 방법]
- 50층부터 적이 플레이어의 패를 보며 플레이한다. 플레이어에게 알리지 않는다 (현재 구현: 없음).
- 보스는 10층 단위로 나온다. 50층 최종 보스, 100층 히든 보스(FR 확정 지급).
- 보스 덱 예: 무금제 사이칼리에어고즈, 무금제 키메라원턴킬. 둘 다 고난이도 보스다. 현재 구현: 보스 덱이 따로 없다 (일반 전투 층처럼 무작위).
- 보스·이벤트 캐릭터는 코인 토스에 영향을 줄 수 있다 (예: 반드시 앞면).
- [미정] 층별 상대 구성, 중간 보스, UR 확정 지급 보스, 50층 최종 보스 보상.

## 화면 구성

듀얼 화면은 왼쪽 플레이어 정보, 가운데 필드, 오른쪽 로그의 3열로 나눈다. 필드는 실제 카드 배치를 점대칭으로 옮기고 엑스트라 몬스터 존은 두지 않는다.

- 왼쪽: 위에 상대, 아래에 나의 초상화와 LP
- 패: 상대 패는 상대 필드 위, 내 패는 내 필드 아래에 둔다.
- 묘지는 묘비 아이콘으로 표시하고, 제외 존은 묘지 바로 옆(필드 가운데 쪽)에 원형 칸으로 둔다.
- 센터 카드: 필드 한가운데에 LP가 더 높은 플레이어가 설정한 카드를 보여 주는 치장 요소다. LP가 역전될 때마다 바뀐다. 듀얼 시작 시에는 코인 토스에서 이긴 쪽, LP가 같아지면 변동 전 LP가 더 높았던 쪽의 카드를 보여 준다. 도전과제를 달성하거나 특정 캐릭터에게 승리하면 얻는다 (현재 구현: 없음).
- 체인: 체인이 발생하면 센터 카드를 완전히 지우고 그 자리에 체인 박스를 올린다. 체인 카드는 박스 안에 1, 2, 3 순서로 겹쳐 쌓인다. 체인할지 묻는 방식은 설정에서 고를 수 있게 한다 (DS 게임의 체인 설정 참고). 현재 구현: 체인 박스 없이 글 목록.
- 효과문: 카드 효과문은 내 초상화 자리에 표시한다.
- 크게 보기: 패, 필드, 로그에서 카드를 길게 누르면 카드를 크게 볼 수 있다.

탑 진행 화면 (현재 구현):

- 탑 화면: 지금 10층 묶음을 쌓아 보여 주고, 지나온 층과 미리보기 범위의 층 종류를 표시한다. 나머지 확률 층은 "?".
- 층 사이 화면: 메인·엑스트라·사이드·봉인·상점 덱 칸, 카드 정보, 끌어다 놓기로 덱 ↔ 사이드 덱 교환, 런 로그.
- 이벤트 창: 상황 글, 선택지, 잠긴 선택지의 조건, 처음 고르는 선택지의 결과 숨김, 결과 창, 이벤트 전투 안내 창.
- 이벤트 도감: 런 시작 화면에서 연다 (완성한 이벤트 수 / 전체).
- 보상 선택 창: 후보 카드 중 고르기 (빈 자리는 골드 표시). 보스 보상의 봉인 해제 고르기.
- 칩교환소·휴식 창: 층에 들어가면 한 번 뜬다.
- 아이템 카드: 카드 정보의 적용 버튼, "적용 중"·"귀속" 표시, 귀속 카드는 사이드 덱으로 빼기 잠금.
- 코인 토스: 이기면 선공·후공을 고르는 창.
- 아직 없음: 카드 버전 표시 (같은 이름의 에라타 전·후 버전 구별).

## 연출

카드 효과가 발동하면 화려한 이펙트 대신 화면 옆 로그에 처리 과정을 기록한다.

- 로그 항목: 턴·페이즈, 발동한 플레이어와 카드, 체인 번호, 처리 결과(LP 변화, 이동한 카드)
- 연출 제작 부담이 적고, 체인이 어떤 순서로 처리됐는지 그대로 보여서 디버깅에도 쓸 수 있다. 로그는 엔진이 보내는 이벤트 메시지를 바탕으로 만든다.
- 런 로그: 층 진입, 듀얼 결과, 보상, 봉인, 칩, 구매, 이벤트, 아이템 적용 등 런의 일을 차례로 남긴다.

## 개발 단계

룰 처리와 카드 효과는 YGOPro 계열 오픈소스 엔진인 ocgcore와 Project Ignis의 카드 스크립트·카드 DB를 가져다 쓴다. 이들은 AGPL 계열 라이선스라 이 게임도 소스를 공개한다.

1. 미정 사항은 개발과 병행해 채운다 (로그라이크 층에 필요한 것부터)
2. 유니티 프로젝트 생성 + 공개 Git 저장소 (완료: Unity 6.3 LTS, 저장소 DuelRoguelike, AGPL-3.0)
3. ocgcore를 빌드해 유니티에 연결하고, 카드 DB와 스크립트 불러오기 (완료)
4. 최소 듀얼: 엔진 메시지를 필드와 로그에 표시하고, 플레이어 입력을 엔진에 전달 (완료)
5. 스타터 덱 4개로 듀얼 테스트, 한글 카드명·효과문 입히기 (완료)
6. 상대 AI: WindBot Ignite 연결 (완료, 난이도 하나)
7. 로그라이크 층 (진행 중)
   - 완료: 탑 구조, 봉인·보충·런 종료, 승리 보상 3장 중 1장, LP 규칙, 칩·칩교환소·휴식·보스 보상, 골드 정산, 컬렉션·덱 편집, 저장·이어하기, 코인 토스 선후공, 이벤트 시스템(견본 12개)·도감, 상점 덱·아이템 카드(견본 2개)·귀속
   - 남음: 골드 쓰는 곳(사이드 덱 확장, 컬렉션 분해, 팩·스트럭처 덱), 투입 코스트, 보스 덱·층별 상대 구성, 층별 AI 난이도·50층부터 패 보기, 무한 모드
8. 카드풀 확장

시험 도구: `tools/headless-run.ps1`로 Unity 없이 컴파일·런 규칙 자가 시험(엔진 없이)·헤드리스 런(양쪽 WindBot)을 돌린다. 헤드리스 런은 런 규칙을 따로 다시 계산해 맞춰 보고(규칙 검사기), 저장·재현이 같은지도 본다. 화면은 Unity PlayMode 시험으로 본다.

## 세션 이동 가이드

새 세션은 이 문서 링크와 아래 시작 문구로 연다. Claude Code 세션은 이 링크를 읽지 못하므로, 문서를 Markdown으로 내보내 저장소의 docs/DESIGN.md에 두고 프로젝트 루트의 CLAUDE.md로 안내한다. 결정 사항의 기준은 대화가 아니라 이 문서다.

### 시작 문구 (복사해서 사용)

```
유희왕 로그라이크 팬게임을 개발 중이야.
설계 문서: https://claude.ai/artifact/KJwunpA4NBRrGz4jYg84t1
이번 세션 목표: (예: ocgcore를 빌드해 유니티에 연결)
관련 파일: (첨부하거나 프로젝트 폴더 연결)

규칙:
- 설계 문서를 먼저 읽고, 결정 사항과 다르게 가야 하면 먼저 말해줘
- 유희왕 카드는 공식 한글 카드명이나 통용 약칭으로 써줘
- 세션이 끝날 때 결정되거나 바뀐 내용을 요약해서 설계 문서에 반영해줘
```

### 세션 나누는 기준

| 세션 | 목표 | 준비할 것 |
| --- | --- | --- |
| 기획 | 규칙, 수치, 미정 사항 결정 | 설계 문서 |
| 엔진 연결 | ocgcore 빌드, 유니티 연결, 카드 DB·스크립트 불러오기 | PC, 프로젝트 폴더 연결 (Claude Code 또는 데스크톱 앱) |
| 듀얼 화면 | 필드, 패, 로그, 체인 박스, 센터 카드 UI | 화면 구성 섹션, 관련 스크립트 |
| 한글 데이터 | 카드명·효과문을 카드 ID별로 입히기 | 스타터 덱 4개 카드 목록 |
| AI | WindBot 연결, 덱별 AI | 상대 덱 목록 |
| 로그라이크 층 | 탑, 보상, 봉인, 재화, 이벤트, 아이템, 컬렉션 | 해당 규칙 절, 관련 미정 사항 |
| 디버깅 | 버그 하나 해결 (버그마다 새 세션) | 재현 방법, 로그, 관련 파일 |

### 세션 루틴

1. 시작: 시작 문구에 이번 목표를 하나만 적는다.
2. 진행: 기능 하나가 끝날 때마다 Git에 커밋한다.
3. 종료: 결정되거나 바뀐 내용을 요약받아 이 문서에 반영하고, 미정 사항을 체크한다.
4. 대화가 길어져 앞 내용을 놓치기 시작하면 요약받고 새 세션으로 옮긴다.

이 게임 전용 Claude 프로젝트를 만들어 세션을 한곳에 모으면 지난 대화를 찾기 쉽다.
