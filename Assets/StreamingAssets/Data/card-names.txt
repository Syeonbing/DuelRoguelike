# 카드명 덮어쓰기 표. 한글 DB(External/edopro-korean/cards.cdb)의 카드명이 공식 한글 카드명과 다른 카드만 적는다.
#
# 형식: 한 줄에 카드 하나, "카드코드 공식 카드명". 카드코드 뒤 첫 공백(또는 탭) 다음부터 줄 끝까지가 카드명이다.
#   카드코드는 BabelCDB의 ID. # 으로 시작하는 줄은 주석이고 빈 줄은 건너뛴다 (카드명 안의 #은 주석이 아니다).
#   게임은 카드 DB와 한글 DB를 읽은 뒤 이 표로 카드명을 바꾼다. 효과문은 바꾸지 않는다.
#
# 기준: 공식 한국 카드 데이터베이스 Yu-Gi-Oh! Neuron (https://www.db.yugioh-card.com/yugiohdb/?request_locale=ko).
#   한글 DB는 이름 안의 줄표를 반각(-)으로 적는 것이 관례라, 전각(－)만 다른 카드는 적지 않는다
#   (예: 「만화경 -화려한 분신-」. 다른 카드의 효과문도 반각으로 적혀 있다).
# 고친 뒤 확인: pwsh -File tools/headless-run.ps1 -CheckOnly
